#  Multi-Agent Agentic Coding Assistant
An advanced AI engineering pipeline built with **LangChain** and **Groq** that transforms natural language requirements into fully structured software projects.

---

##  The Architecture
This project demonstrates **Agentic Design Patterns** by breaking down a monolithic coding task into a specialized multi-agent workflow:

1.  **Strategic Planner**: Analyzes user intent and defines the project structure (HTML, CSS, JS).
2.  **Senior Architect**: Generates technical blueprints and function-level logic for each file.
3.  **Lead Developer**: Executes the blueprints to generate pure, production-ready source code.
4.  **File Automator**: Uses Python's `os` bridge to physically construct the directory and save files to disk.



---

##  Tech Stack
* **Orchestration**: LangChain (Python)
* **Inference Engine**: Groq Cloud (LPU Hardware)
* **Models**: Llama 3.3 70B (Versatile)
* **DevOps**: Git, Python-Dotenv
